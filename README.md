# Digital Clock - Multiple Time Zones

A beautiful, responsive web application that displays the current time in different time zones around the world.

## Features

✨ **Multiple Time Zone Display**
- View current time in multiple time zones simultaneously
- Displays time, date, and timezone name for each location

🎨 **Beautiful UI**
- Modern gradient background
- Smooth animations and hover effects
- Fully responsive design (desktop, tablet, mobile)
- Card-based layout for each timezone

➕ **Add/Remove Timezones**
- Dropdown selector with 20+ major world cities
- Add timezones dynamically
- Remove timezones with a single click
- Default 4 timezones: New York, London, Tokyo, Sydney

⏰ **Real-Time Updates**
- Clock updates every second
- Accurate time conversion using JavaScript's `toLocaleTimeString()`
- No external dependencies

## How to Use

1. **Open the Application**
   - Simply open `index.html` in your web browser

2. **View Current Time Zones**
   - The app displays 4 default time zones on load

3. **Add a New Time Zone**
   - Select a timezone from the dropdown menu
   - Click the "Add" button
   - The new clock will appear in the grid

4. **Remove a Time Zone**
   - Click the "Remove" button on any clock card
   - That timezone will be removed from the display
